# 22. What C+++ combines

```
        JavaScript
            │
      familiar syntax
            │
            ▼
      ┌───────────┐
      │   C+++    │
      └───────────┘
       │    │    │
       │    │    └── C/C++ ecosystem access
       │    │
       │    └─────── automatic memory management
       │
       └──────────── static typing
            │
            ▼
        C++ backend
            │
            ▼
        native code
```

Target: **TypeScript's familiarity + C++'s native performance + automatic memory management + a modern package ecosystem.**
