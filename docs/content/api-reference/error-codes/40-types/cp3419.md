# CP3419 — Invalid argument value

**Stage:** semantic analysis — types · **Const:** `diagcode::kInvalidArgumentValue`

## What it means
An argument has a value the callee cannot accept — today, most notably a `console.on` / `console.off` event name outside the documented set.

## Why it fires
The console event surface is a finite API contract (D75): only `"keypress"`, `"line"` and `"close"` can fire, so any other literal is a program error, and the check reports it at the call, not at the listener (`src/std/console/codegen.cpp`): `console event must be a string literal: expected "keypress", "line" or "close"` for a non-literal event, or `unknown console event '<name>'; expected "keypress", "line" or "close"` for an out-of-set one. The same code reports other value-shaped argument problems at emission: `console.table` on a non-printable argument, a constructor spread that is not an array (or whose elements have no C++ spelling), or a spread not in last position of a class constructor call. The diagnostic is reported during code generation, so it surfaces under `cp3 build` / `cp3 run` / `cp3 dev`; `cp3 check` accepts the program until then.

## Minimal reproducer
```ts
// fails with CP3419
import console from "std/console";
console.on("data", (value) => { console.log(value); });
```
`"data"` is not one of the three documented console events, so the compiler reports `unknown console event 'data'`. The legal spelling uses one of `"keypress"`, `"line"`, `"close"`. This exact case is pinned by `tests/cases/stdlib/01/console/event/console_event_unknown_error`; `tests/cases/stdlib/01/console/on/console_on_computed_event_error` pins the non-literal event form (`console event must be a string literal`). See [Console](../../../standard-library/01-console.md).

## What happens
Compilation stops at the code-generation stage; nothing is produced. The diagnostic carries `CP3419` and spans the offending argument.

## How to fix
1. Use a documented console event: `"keypress"` (each key), `"line"` (each completed line without its terminator), or `"close"` (stdin reached EOF).
2. The event must be a string *literal* — a computed `const event: string = "line"` is rejected even when its value is known; inline the literal.
3. For `console.table`, pass an array of printable values or an object literal; for constructor spreads, spread an array in last position.
