# CP3420 — Void type banned

**Stage:** semantic analysis — types · **Const:** `diagcode::kVoidTypeBanned`

## What it means
The retired `void` spelling was used as an annotation — a variable, parameter, return type, type alias, type argument, or any other annotation position.

## Why it fires
Older annotation spellings carried the JS habit of spelling “returns nothing” as `void`, which was ambiguous and is gone from the language. Every annotation position names a real type node, so the check sits in `resolveNamedType` (`src/sema/src/checks/type/type_check.cpp`) and fires everywhere a `NamedType` is resolved, including nested positions (`Promise<void>`, `void[]`). The diagnostic is `the 'void' type is removed; annotate the return as 'undefined' instead`. The name still *resolves* — to `undefined` — so misannotated programs type-check against the intended type; only the spelling is illegal. The compiler's internal “returns nothing” sentinel is unaffected.

## Minimal reproducer
```ts
// fails with CP3420
import console from "std/console";
function f(): void { return 1; }
console.log("unreachable");
```
`void` is a banned annotation spelling, so the declaration reports `the 'void' type is removed; annotate the return as 'undefined' instead`. The legal annotation is `undefined` (`function f(): undefined { return; }` — or `f()` returning undefined). This exact case is pinned by `tests/cases/types/05/void/void_return_value_error`; `tests/cases/functions-closures/03/void/void_bare_return` and `tests/cases/generics/01/generic/generic_object_field_void_error` pin the same code in other annotation positions.

## What happens
Compilation stops; nothing is produced. The diagnostic carries `CP3420` and spans the banned annotation.

## How to fix
1. Replace the annotation with the intended type: `undefined` for “returns nothing”; a concrete type otherwise.
2. In a type argument (`Promise<void>`), write `Promise<undefined>` for the same meaning.
3. If the value is an untyped payload, this is not the code you want — that is a banned `unknown` spelling, reported as CP3421.
