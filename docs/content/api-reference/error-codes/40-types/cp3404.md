# CP3404 — Not callable

**Stage:** semantic analysis — types · **Const:** `diagcode::kNotCallable`

## What it means
Something is being called as a function that is not a function: a number, a class, a native type, or `super` outside its place.

## Why it fires
The call-position check fails in a few distinct ways. The general call checker reports `value of type '<T>' is not callable` when the callee's type has no signature (`src/sema/src/checks/call/call_check.cpp`). A derived class constructor that never calls `super(...)` reports `constructor of class '<C>' must call super(...) because it derives from '<B>'` (`src/sema/src/checks/class/class_check.cpp`). `super(...)` outside a derived constructor, called twice, or with no base reports the matching `super(...)` message, and a native type used as a callee reports `'<namespace>.<name>' is a native type, not a callable function` (`src/sema/src/checks/type/native_check.cpp`). Calling a class without `new` — e.g. `WebSocket("ws://…")` — reports the same family.

## Minimal reproducer
```ts
// fails with CP3404
const n = 5;
n(1);
```
`n` has type `number`, which is not callable, so the compiler reports `value of type 'number' is not callable`. The legal form calls an actual function or a value of function type. `tests/cases/classes/03/super/super_missing_call_error` pins the same code for a derived constructor that never calls `super`; `tests/cases/stdlib/02/network/class/network_class_called_without_new` pins it for a class called without `new`.

## What happens
Compilation stops; nothing is produced. The diagnostic carries `CP3404` and spans the call.

## How to fix
1. If the callee is a class, construct it with `new`; if it is an interface object with a call signature, call it as a function value instead.
2. If the callee is `super`, move the call into the derived constructor, and call it exactly once before any use of `this`.
3. If the callee is a value of the wrong type, check the annotation: the value was probably narrowed (or widened) along the way; keep the call where the value's type is a function.
