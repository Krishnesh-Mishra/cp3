# CP3001 — Internal error

**Stage:** internal — compiler · **Const:** `diagcode::kInternalError`

## What it means
The compiler hit a state it believes is impossible or unsupported internally. This is a compiler bug, not a problem with your source: no CP3 program is *supposed* to trigger it.

## Why it fires
There is no source-level check behind this code. It is emitted by defensive paths that should be unreachable: the language-server glue catches an exception from the checker and reports `internal error while checking: <what>`; the code generator reports it for statement or pattern forms with no lowering (for example `unsupported statement kind` in `src/codegen/src/emit/decl/stmt.cpp`), and the typed-array and class paths use it for unsupported internal shapes. A report with CP3001 always means "the compiler broke," never "your code is ill-formed."

## Minimal reproducer
There is no source-level reproducer: any input that provokes CP3001 is a defect to report. The useful form is a bug report:

```ts
// a program that (unexpectedly) makes the compiler trip CP3001
// + the full diagnostic output, cp3 version, and the OS/typeSystem settings
```

If you see this, minimize the program as far as you can before reporting; a smaller reproducer pins the bug much faster.

## What happens
Compilation stops; the diagnostic carries `CP3001` and, in the language server, the underlying exception text. Nothing is produced for the failing file. This is the one diagnostic that is never a "fix your code" signal.

## How to fix
1. Update to the latest CP3 toolchain and re-run — the bug may already be fixed.
2. Minimize: reduce the program to the smallest source that still triggers it.
3. Report it as a compiler issue with the full output, `cp3 version`, the OS, and the selected `typeSystem`. See [Diagnostics and generated help](../../../cli-and-compiler/06-diagnostics.md).

## Related codes
- None — CP3001 is the only code in the internal family. Ordinary source problems are reported as CP32xx (syntax), CP33xx (names) or CP34xx (types).
