# CP3607 — Native binding is invalid

**Stage:** semantic analysis — modules · **Const:** `diagcode::kNativeBindingInvalid`

## What it means
A manifest for a native binding exists at `.cp3/native/<id>/native.json`, but it is not usable: not valid JSON, missing or wrong `schema`, malformed fields, or an `index.cp3` missing next to it when the binding records a content hash.

## Why it fires
Reported by the module loader when it reads the binding's `native.json` (`src/common/src/native/native_bindings_read.cpp`, via the native-import resolver). The message comes from the reader, e.g. `the native binding metadata is not valid JSON: <parse error>`, `the native binding metadata has no 'schema' field`, `the native binding metadata has schema '<seen>', but this compiler reads '<expected>'`, or `the native binding metadata is invalid: <field>`; a missing `index.cp3` for a hash-recording binding is reported the same way. A remedy line (`re-run 'cp3 native-install <sdk> --name <id> --force'` or the reader's own message) is appended to the diagnostic.

## Minimal reproducer
```ts
// fails with CP3607
// .cp3/native/demo/native.json contains malformed JSON or a wrong schema;
// src/index.cp3:
import native "demo" as dm;
import console from "std/console";

console.log(dm.add(2, 3));
```
The legal form is a well-formed binding produced by `cp3 native-install` with the schema this compiler reads. No conformance fixture pins CP3607 in this tree; the shape follows `tests/cli/cases/pkg/native-import.json` (`check-rejects-a-stale-binding` shows the sibling stale case).

## What happens
Compilation stops at the front end; nothing is emitted; the diagnostic carries the code. The remedy in the message is the fix.

## How to fix
1. Re-run `cp3 native-install <sdk> --name <id> --force` to regenerate the binding cleanly.
2. If the binding was hand-written, fix `native.json` to match the expected schema (`cp3-native-binding/1`) or drop the bogus fields named in the message.
3. If a schema-mismatch message appears, upgrade the compiler or regenerate the binding with the same compiler version.
