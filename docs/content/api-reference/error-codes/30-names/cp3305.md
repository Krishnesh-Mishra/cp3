# CP3305 — Member not found

**Stage:** semantic analysis — names · **Const:** `diagcode::kMemberNotFound`

## What it means
The object resolves, but the member you asked for does not exist on it — a typo'd property, a std-module surface that is closed, or a private member read from outside its class.

## Why it fires
Member resolution on a closed surface reports `'<receiver>' has no member '<prop>'` with a `did you mean '<candidate>'?` suggestion when a close name exists (`src/sema/src/semantic_analyzer.cpp`, `reportMemberMiss`). It fires for closed std namespaces (`Math`, `console`, `process`, `Date`, `RegExp`, the collections family, …) whose member sets are pinned tables, for unknown members of user classes (including private/protected access from outside), and for EventEmitter member misses. A member that exists but must not be called is CP3404; a member that exists with the wrong shape reports CP3401. The receiver being `unknown` is CP3414, not this code.

## Minimal reproducer
```ts
// fails with CP3305
import Math from "std/math";
let x = Math.logh(2);
```
`Math` has no member `logh` (the surface is closed), so the compiler reports `'Math' has no member 'logh'; did you mean 'log'?` — the exact suggestion depends on the candidate set. This case is pinned by `tests/cases/diagnostics/math_unknown_member`. `tests/cases/diagnostics/console_logh_suggestion` and `tests/cases/diagnostics/object_member_miss` pin the same code for the console namespace and for a plain object shape.

## What happens
Compilation stops; nothing is produced. The diagnostic carries `CP3305` and spans the offending property access.

## How to fix
1. Check the suggestion first — a transposed letter in a std member is the most common cause, and the compiler names the intended member.
2. Compare the spelling against the module's guide page: standard modules have closed supported surfaces, and a similarly named Node or browser API is not automatically available. See [Global builtins](../../../language/99-global-builtins.md).
3. If the receiver is your own class, check the member's visibility — a private or protected member read from outside the class reports this code.

## Related codes
- CP3301 — Undefined identifier (the whole receiver is unresolved, not just the member)
- CP3304 — Unresolved import (the member may exist, but the import form is wrong)
