# CP3915 — Worker listener parameter

**Stage:** semantic analysis — concurrency · **Const:** `diagcode::kWorkerListenerParameter`

## What it means
A worker listener (`on("message", l)` / `on("error", l)`) has a parameter that does not match the message payload: not a name or an object pattern over the payload, a pattern naming fields the payload does not carry, or a pattern on a channel direction that carries nothing.

## Why it fires
Checked when the listener arrow is lowered (`src/codegen/src/emit/worker/worker_listener.cpp`). Messages seen: `this worker listener's parameter must be a name or an object pattern over the message payload`, `this worker listener's parameter does not match the message payload type`, `this worker listener's parameter names '<name>', which the message payload does not carry`, `this worker listener has no message payload (the channel direction is empty), so its parameter cannot bind anything`. (An `"error"` listener carries the thrown value, not a channel payload, and is exempt from the payload match.)

## Minimal reproducer
```ts
// shape — verify against a listener-parameter fixture (none pins CP3915 yet)
const w = new Worker((thread: Thread<{ n: number }, number>) => {
  thread.on("message", ({ bogus }) => {
    thread.postMessage(1);
  });
});
w.terminate();
```
The legal form destructures fields the payload actually carries (`{ n }`), or uses a plain name parameter (`(data) => ...`). No conformance fixture pins CP3915 in this tree; the shape follows the listener lowering in `worker_listener.cpp` (the payload record `{ n: number }` has no `bogus` field).

## What happens
Compilation stops; nothing is emitted; the diagnostic carries the code.

## How to fix
1. Fix the pattern to fields the payload carries (`{ n }`), or use a plain parameter and read the fields from it.
2. If the channel direction is `undefined`, the listener takes no parameter at all — drop it.
3. If you need one payload shape everywhere, put the missing field on the record type at the annotation site so both sides agree.
