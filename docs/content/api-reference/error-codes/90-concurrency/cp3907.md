# CP3907 — Worker payload is not copyable

**Stage:** semantic analysis — concurrency · **Const:** `diagcode::kWorkerPayloadNotCopyable`

## What it means
A value being sent across the worker boundary is not a deep-copyable value type — a function, a class instance with function members, a handle, a promise, or a record carrying one of those. Worker messages are deep copies, so the value must have a value spelling.

## Why it fires
Checked when the worker send/receive surface is lowered (`src/codegen/src/emit/worker/worker_handles.cpp`, `worker.cpp`), when the worker channel's payload types are resolved for a new worker unit (`worker_module.cpp`), and for listener payloads (`worker_listener.cpp`). The diagnostic reports `worker messages are deep-copied: payloads must be copyable value types (numbers, strings, booleans, arrays, records, enums, or unions/options of those)` (or the unit-level `worker channel payloads must be copyable value types (...)`).

## Minimal reproducer
```ts
// fails with CP3907
const w = new Worker((thread: Thread<{ fn: () => number }, number>) => {
  thread.on("message", (data) => {
    thread.postMessage(data.fn());
  });
});
w.terminate();
```
The legal form sends only value payloads: `Thread<{ n: number }, number>` — records whose fields are all value types. Pinned by `tests/cases/concurrency/worker/check/worker_check_function_payload` and `tests/cases/concurrency/worker/channel/worker_channel_function_payload`.

## What happens
Compilation stops; nothing is emitted; the diagnostic carries the code.

## How to fix
1. Replace non-value fields with values: numbers, strings, booleans, arrays, records, enums, or unions/options of those.
2. Split the payload: send the data, and rebuild behavior on the receiving side (a function reference cannot cross the boundary at all).
3. If the payload is a class instance, model it as a record of its value fields; class instances with function members are not deep-copyable.
4. If you need a rich object graph, keep it on one side and send the identifying values only.
