# CP3201 — Unexpected token

**Stage:** parser · **Const:** `diagcode::kUnexpectedToken`

## What it means
The token stream does not match the grammar at the current position: the parser found a token it has no rule for here. This is the general "syntax error" code; the message after `syntax error: ` names the expected shape.

## Why it fires
Throughout the parser, a grammar rule is violated and recovery begins: `expected a property name after '.'`, `expected an expression after 'throw'`, `expected a binding name`, `expected a module specifier string`, `multiple inheritance is not supported`, `generators are not supported`. The parser's `report()` prefixes every message with `syntax error: ` (`src/parser/src/core/tokens.cpp`), so the printed diagnostic reads `syntax error: …`. Specific expectations that know exactly which token they awaited are reported as CP3202; this code is the catch-all for shapes with no rule.

## Minimal reproducer
```ts
// fails with CP3201
const handler = (value: number) => {
  value.;
};
```
After `value.` the parser requires a property name and finds `;`, so it reports `syntax error: expected a property name after '.'`. This exact case is pinned by `tests/cases/syntax/03/unexpected/sync_arrow_missing_member`; `tests/cases/classes/02/multiple/multiple_inheritance` pins the same code for `class C extends A, B`.

## What happens
Compilation stops before semantic analysis; nothing is produced. The diagnostic carries `CP3201`; the parser reports the earliest violated rule and then recovers to the next statement, so fix the first diagnostic first.

## How to fix
1. Read the message after `syntax error: ` — it names the expected shape (`expected a property name`, `expected a module specifier string`, …).
2. Check the construct at the reported span for a missing name, operator or separator.
3. If the message is a deliberate feature ban (multiple inheritance, generators, named-call arguments), rewrite with the supported form the message implies; the diagnostics guide explains the related diagnostics pipeline: [Diagnostics and generated help](../../../cli-and-compiler/06-diagnostics.md).
